# AGENTS.md — rulertoo

## Project
On-screen X11 ruler with real physical dimensions from XRandR.
Borderless, draggable, resizable, rotatable; units cm/mm/in/px.

## Build
- `nix develop` / `nix build` / `nix run`
- CMake + Ninja
- Deps: libx11, libxrandr, libxext, libxrender
